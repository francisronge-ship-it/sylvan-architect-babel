  `svg.selectAll('*').remove()`): acceptable at Babel's tree sizes (tens of
  nodes); per-step scrubbing already uses cheap opacity toggles. Not worth a
  perf plan.
- **`spawnSync` blocking the event loop for local-model calls**
  (`modelRuntime.js:131-148`): local-only research path, single-user; by
  design.

  Vercel / Vite dev): deployment-specific constraints justify parallel
  implementations; plan 005 extracts only the shared guard logic. Full
  unification rejected as churn without payoff.

  (`server/parseApi.js:30-37`): fine for sentence-level linguistic input; by
  design (prompt-injection hygiene).

  HTTP 400** (`parseRoutes.js:178`): cosmetic status misclassification on rare
  provider errors; not worth a plan.

  need at one-route SPA scale.
- **`dailyUsageByIp` prune-at-20k** (`server/index.js:92-99`): adequate; plan
  005 ports it as-is.
- **README "Parse 1 / Parse 2" ambiguity feature dormant** (current contract
