## 2. The formal object

A **Babel derivation** is **D = ⟨S₁…Sₙ, ι, π, K⟩**: successive complete workspaces (`workspaceForest`; Sₙ converges on the exact input tokens); occurrence identity ι (persistent node `id`s; `lineageId` classes = chains; identity only — never dependency, direction, or operation; live rule `systemInstruction.js:86` [VERIFIED-CURRENT]); pronunciation π (`word`/`tokenIndex` anchor overt occurrences; `silent: true` is an authored commitment preserving full structure; nulls are authored, never inferred); commitment layer K authored as `relations` — stage-indexed open-named assertions with same-stage witnesses (`anchors`: open role names → node IDs or ID arrays; every anchor resolves in that stage's expanded workspace, `systemInstruction.js:96–102` [VERIFIED-CURRENT]) and optional relation information (§3.2). A CE-2 candidate extension (**F-T**) adds an optional `priorAnchors` block — open roles resolved deterministically in the **immediately preceding** stage's expanded workspace — so identity/existence transitions (fusion, fission, node deletion, replacement without id persistence) are machine-witnessed on both sides; state changes on persisting objects already resolve through persistent ids (PROOF §2 transition table). `statement` orients; `stageRecord` licenses; renderer construction steps are never authored stages (live rule, line 114). No authored operation ledger; no authored build order (within-stage order is recoverable from containment; order that is an analytic commitment surfaces as stage granularity — live rules 116–117). Poles argument: state-sequence authoring (Collins & Stabler 2016, [PDF](http://www.its.caltech.edu/~matilde/CollinsStabler2016MinimalistSyntax.pdf), SEARCH-VERIFIED) over operation-tree authoring (Stabler MG), because the operation pole demands a closed per-framework calculus, does not describe X-bar practice, and reproduces Babel's failed ledger era [HISTORICAL: cleanup `9082d41`].

### 3.2 Relation information (recommended candidate; enters CE-2 only if its factor evidence passes and Francis explicitly approves the field name and conventions [FRANCIS])

Field `values: Record<string, string | string[]>` beside `anchors` (name recommended over `info`/`content`/`data`/`properties` on the content-shape argument — key→literal symmetry with `anchors`, and the name itself signals short literals under named keys, the built-in prose-dump deterrent; the name remains formally open, with an optional one-token `values`-vs-`info` A/B riding the CE-2 arm). **Types (strict):** string, or array of strings — nothing else; a number, boolean, null, or object value is a typed class-3 error naming the key and received type (Babel never silently rewrites authored content; JSON parsing does not preserve number spelling, so numeric literals must arrive as quoted strings to keep their exact decoded form); empty string legal; empty array a typed error (assert nothing by omission); duplicate array entries preserved and displayed. **Order:** array order survives JSON parsing exactly and is displayed as authored; the contract does not declare order meaningful — a relation's own semantics (or a registry signature) may. **Multiplicity (the semantics):** a relation item ⟨name, anchors, priorAnchors?, values⟩ asserts exactly **one instance** of the relation holding of its assignment: array-valued roles participate **jointly** in that single instance (natively a hyperedge); parallel/distributive/repeated commitments are authored as that many items; asserted grouping of instances is itself a commitment, authored as a covering relation; exact duplicates (same stage, name, assignment, values) are flagged `duplicate_relation`, displayed with a multiplicity marker, never silently dropped; role association holds only within an item; renderer clustering of same-name items is labeled presentation, asserting nothing. No prefix conventions, equal-length rules, or broadcasting exist — none are needed (PROOF §2 re-derives every former adversarial case). **Transitions:** the optional `priorAnchors` block (F-T) — open roles → ids resolved in the **immediately preceding** stage's expanded workspace; meaningful only at stage index ≥ 1; at least one anchor block non-empty; deterministic validation against stage k−1; the invention detector's universe for such a relation is the union of the two adjacent stages' authored ids. **Relation-instance cross-reference — bounded exclusion, not a resolution:** relations do not reference other relations. Attested needs are self-contained — a failure/override/ordering claim authors its own relation carrying its participants and content (a failed-Agree relation anchors probe/goal and states the outcome; an override anchors the persisting witnesses and states the superseded value as a literal; operation order is stage placement; same-stage grouping is a covering relation). The residual case — structurally citing exactly one of several same-stage, same-name, same-witness instances differing only in values — has no deterministic encoding in the current contract and is **excluded as unsupported by any attested register row**; the minimal future mechanism (optional derivation-unique relation `id` + `targets` reference block) is specified in PROOF §2 as designed-but-not-adopted, and adoption would be its own CE factor. Literals: compared by exact decoded-string (code-point) identity, never parsed further; never node IDs (flag `value_matches_node_id`); never stage references; label duplication flagged (`value_duplicates_label`), never rejected; verbatim notation strings welcome as display literals. **Prose discipline (stated, review-enforced, not mechanically policed):** each key names one relation-local aspect; each value is its authored literal; argumentation belongs in stageRecord — no length thresholds exist (the deleted-threshold rule stands); the benchmark's discipline dimension may cite misplaced prose as a specific defect. Model-facing wording: abstract category description, zero linguistic examples, completeness invitation mirroring the live anti-minimization rule (line 131); the entire authored-convention surface is: "arrays are ordered as authored; the roles of one relation hold jointly; state parallel commitments as separate relations."

## 5. Transport, reliability, generation

### 5.1 Failure taxonomy (normative)

(1) **transport/serialization** — not-JSON; fenced/wrapped; delimiter damage; transport-stringified sub-values; misplaced fields; (2) **incomplete generation** — length-stop truncation (finish reason checked before any parse) or valid carrier whose derivation never converges on the input; (3) **contract misunderstanding** — missing/extra fields; unresolved anchors; token misalignment; silence misuse; incomplete leaves; (4) **linguistic failure** — evaluation's business, never error handling's; (5) **deterministic engine failure** — Babel's defect: fix, re-run, never score; (6) **valid-but-unexpected analysis** — flows through untouched. Every rejection reports class, rule ID, stage index, field path, and the exact offending value, with raw output downloadable; the generic messages (`parseNormalization.js:228` [VERIFIED-CURRENT]) are retired. **Fidelity layers (exact; used by every "verbatim"/hashing claim in this packet):** (1) archived raw response bytes — byte-preserved and sha256-hashed; (2) parsed values — JSON parsing does not preserve source escapes, number spelling, duplicate object keys, or wrapper bytes, but does preserve each decoded string's exact Unicode content and every array's order, and Babel preserves those; (3) canonical reserialization — a derived form for hashing and display, never the original byte stream. "Verbatim" display and "exact comparison" mean layer (2) — decoded-content identity; byte identity and content-addressing mean layer (1).

## 6. Quality protocol (zero confirmed regression; sequential)

**Principle:** statistics can only **reject** or **hold**; adoption requires per-loss adjudication with zero confirmed regressions; every uncertainty resolves to the incumbent [SETTLED-4]. **Authority scoping:** Francis performs the blinded verdicts and the per-loss adjudications; **the protocol itself contains no override** — a loss adjudicated real rejects the factor, and nothing can be adopted *through this protocol* carrying a confirmed regression. Francis's standing authority to change the product or contract outside this protocol is untouched, but any such change is a separate act outside this evidence path, never an approval issued by it.
**Design:** blinded, order-randomized paired comparisons per factor arm (run-index pairing; ties explicit; interleaved **A0-vs-A0 self-pairs** whose only roles are gross-screen calibration and judge-noise context). **Phase 0 (screening; sequential; policy-sized):** the starting batch is a Francis cost-policy declaration made before any run, chosen from stated options with consequences (no size is claimed statistically derived); estimands: gross regression (aggregate exact test against the self-pair rate — this screen can only reject), the self-pair rate, first variance inputs; extends sequentially until its adjudication queue is resolvable and its declared criterion is met; **cannot adopt**. **Phase 1 (adoption evidence; simulation-sized from Phase-0 posterior draws):** adoption requires **all** of: (i) zero losses adjudicated real — every candidate-loss pair unblinded after verdicts and classified with exactly three admissible outcomes: **(a) real regression** → reject the factor — and a genuinely worse candidate output is evidence of harm even when stochastic in origin; **(b) different-but-equal analysis** → discounted and logged, because it is not worse; **(c) not attributable to the factor** — admissible **only** with evidence that the same worse-variation belongs to the *incumbent's own* distribution (it appears among incumbent self-pairs or incumbent reruns) **and** that the factor does not increase its frequency or severity relative to that incumbent baseline (a like-for-like comparison, with no fixed tolerance, percentage, or sample size invented here); **candidate-only variability is never sufficient to discount a loss**. Any pair for which attribution or non-regression cannot be established is treated as (a) where the evidence is adverse, and yields hold/insufficient-evidence where it is merely insufficient — adoption never proceeds over an unresolved loss; (ii) aggregate screen passed — and the aggregate and per-loss rules agree by construction: the aggregate test compares the candidate's loss rate against the incumbent self-pair baseline and can only reject or hold, so neither level can convert candidate-side variability into permission; (iii) **objective harm endpoints (failure-class rates; coherence-violation rates): any confirmed increase — statistically distinguishable from zero at the pre-registered one-sided level — rejects the factor; estimates indistinguishable from zero yield `hold/insufficient evidence`, never adoption; adoption additionally requires the uncertainty to be small enough to exclude a regression at the declared reporting granularity** (a variability band is never permission for known worse output); (iv) for the skeleton factor: zero vocabulary echo and no stage-count compression. **Honest limit:** the self-pair rate measures judge/rerun disagreement only and bounds nothing about undetected systematic degradation; effects below judge discrimination and endpoint sensitivity are undetectable, disclosed, and mitigated only by the objective endpoints and post-adoption monitoring with rollback. **Adversarial checks (binding):** 8–4 against the candidate → reject; 11 ties + 1 real loss → reject; 12 wins with a confirmed coherence increase → reject; all-ties subtle degradation → disclosed limit; cross-provider split → reject globally (the contract is provider-neutral; per-provider prompts are not offered). **Numerical instantiation (parameters declared at S0; recommended defaults are labeled conventions, [METHOD-EXPERT]-reviewable):** the gross screen is a one-sided exact binomial test of the candidate-loss count against the concurrent A0 self-pair rate at α = 0.05 (reject/hold only); adoption additionally requires the one-sided upper 95% bound of each objective-harm difference (failure-class and coherence-violation rates, candidate − incumbent) to lie below the S0 reporting granularity g (recommended initial g = 5 percentage points, derived from achievable pilot widths); any bound straddling g → **hold/insufficient evidence**; the three-valued outcome (adopt/reject/hold) is mandatory at every decision point.
