## Binding rules

1. Preserve the Francis-owned dirty tree; package-owned hunks only; `verify:all` green before/after; every fixture/snapshot diff justified against a packet section.
2. **Contract ownership:** only W6/W7 touch contract-bearing files (`systemInstruction.js`, `prompts.js`, authored-surface `types.ts`, validation semantics).
3. Prohibited tests: exact-output prompt tests; brittle phrase matching; snapshots of model prose. Required: property tests, typed-error assertions, byte/containment audits, deterministic projections.
4. **No path to confirmed-worse output:** model-visible changes ship only through CA §6's protocol; model-invisible engineering ships on offline proof; no package selects sample sizes, carriers, or measurement models — those are consumed from gate outputs.
5. Visual gates ≠ fixtures (VR §6); SVGR entries only via gate passage; styling edits never add, remove, or redirect a semantic mark.
6. Paid calls only in **[launch: Francis]** packages with written BM §12-formula cost estimates — estimates authorize spending and feed measured reporting only; they never shape design quantities, coverage, or adjudication (BM §7.1 quality-first constraint).
7. No deployment, publication, promotion, or database mutation; migrations flagged, class-C, reversible by re-projection; history never rewritten.
8. Drift check per package (HEAD ancestry `006b803`; owned files match; baseline green); on drift, stop.
9. **Generic-infrastructure rule:** where a design is evidence-gated (carrier; measurement model; recovery set; skeleton; tier-coverage policy), packages may build parameterized infrastructure that can express every candidate, and must not default, hardcode, or optimize for one.

Package fields below: **In** = canonical inputs · **Owns** = files/modules · **Class** = model-invisible-safe / gated · **Gate** = required evidence/approval and supplier · **Generic** = what may be built without embodying an unresolved result · **Stop/Roll** = stop conditions and rollback · **Accept** = acceptance proof.
